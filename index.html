Writing with coding agents

LitHarness

Start with a brief, review the story bible, then let Codex or Claude Code plan and draft LitRPG chapters. The rebuilt Python tool keeps story state, checks, and call records in plain files.

  • Checks character stats and chapter constraints in code.
  • Retrieves relevant passages from earlier chapters.
  • Resumes interrupted work from saved call receipts.

The generation pipeline works; assessing literary quality remains an open research problem.

Learned control & simulation

Haltere

A connectome-constrained recurrent network trained to fly a drone in Liftoff. Its 30,000-neuron flight circuit uses fruit-fly connectivity, with learned parameters and a differentiable PyTorch simulator.

Published race result, 25 September 2026: fast-brain-08 completed three laps of Straw Bale in 5:17.805 with explicit pilot assistance.

Research prototype. The newer fast-brain-11 improves obstacle handling but has no completed race. Reliable unseen-course racing and freestyle flight remain unproven.

  • Python
  • PyTorch
  • Differentiable simulation
